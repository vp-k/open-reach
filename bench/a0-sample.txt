# A0 측정 표본 — 실제 리서치 fetch 실패율의 근거 (ADR-005)
#
# 이 파일의 실패율이 10% 미만이면 ADR-005 를 철회하고 프로젝트를 중단한다.
# 따라서 표본이 어려운 사이트로 채워지면 중단 판정을 스스로 회피하는 셈이 된다.
# 표집 규칙을 먼저 고정하고 그 비율대로만 채웠다.
#
# 표집 규칙 — "리서치 중 실제로 본문을 원해서 여는 URL" 의 분포를 따른다.
#   공식 문서        22건 (31%)  가장 많이 여는 곳
#   GitHub            8건 (11%)  코드·릴리스·이슈
#   엔지니어링 블로그 12건 (17%)  기법·사후분석
#   Q&A / 포럼         6건  (9%)
#   뉴스 / 미디어      8건 (11%)
#   패키지 레지스트리  4건  (6%)
#   학술 / 표준        4건  (6%)
#   제품 / 시장 조사   6건  (9%)  경쟁 구도·가격 페이지
#   합계              70건
#
# 의도적으로 하지 않은 것:
#   - 안티봇으로 유명한 사이트를 골라 담지 않았다 (실패율 부풀리기 방지).
#   - 반대로 정적 문서만 담지도 않았다 (실패율 낮추기 방지).
#   - 개별 URL 은 "이 도구가 뚫을 수 있는가" 가 아니라 "리서치에서 실제로 여는가" 로만 골랐다.
#
# 측정 조건: 표준 HTTP 클라이언트, 임퍼소네이션 없음, max_attempts=1, 브라우저 폴백 없음.
# 이 수치는 "아무 대책 없이 그냥 가져올 때" 의 실패율이다 — 개선 전 기준선.
